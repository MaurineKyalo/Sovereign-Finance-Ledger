# Sovereign Finance Ledger

## 📌 The Problem
Many small business owners (like mama mbogas and local shopkeepers) do not own smartphones. Because of this, they are excluded from modern digital financial tracking tools. They rely on cash and memory, making it difficult to separate business funds from personal funds or build a credit history.

## 💡 The Solution
The **Sovereign Finance Ledger** is a USSD-simulated program built in Python. It is designed to run on basic feature phones, allowing traders to:
- Record daily sales and expenses.
- Track their running balance.
- Improve their financial literacy and data sovereignty.

## 🚀 Key Feature: The "Back" Function
Traditional USSD menus often force users to restart the entire session if they make a typo. This system introduces a `0` (Back) option at the input stage, allowing users to correct mistakes without losing their session.

## 🛠️ Tech Stack
- **Language:** Python 3
- **Concepts:** Variables, loops, conditionals, and error handling (defensive programming).
